
# Zzikzzik

Zzikzzik is a **checklist application for creating healthy habits**. User can create goals and break them down into small units of todos to achieve every day. Supports community activities with comments and likes to share my goal achievement with photo and file uploads. 

## 📌 Project Overview
- **Duration**: September 2024 - January 2025
- **Live URL**: ~~[Zzikzzik](https://front-sooty-three.vercel.app/)~~ (run until March 2025)
- **API Documentation**: ~~[Zzikzzik - Swagger](https://zzikzzik.shop/swagger-ui/index.html#/)~~ (run until March 2025)
- **Team Communication**: [Zzikzzik - Notion](https://project-movie-reservation.notion.site/Zzikzzik-1be5998d726680c1aca0fda21c3054bd?pvs=4)

> ⭐️ **Freelance Project:** This project was developed as a contract freelance assignment for **Code-It Company** for two months duration. Cooperated with one backend developer and three front end developers for software developement.
